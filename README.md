# UltraPlay

Site da UltraPlay com planos, conteúdos em destaque, animações automáticas e teste grátis de 3 horas pelo WhatsApp.

## Arquivos

- `index.html`: página principal.
- `styles.css`, `experience.css` e `cinema.css`: aparência e animações.
- `experience.js`: carrosséis, dispositivos, controles de movimento e oferta de teste.
- `assets/`: logo e imagens do site.

## Visualização

Abra `index.html` em um navegador. Não é necessário instalar dependências ou compilar o projeto. Para hospedar, use a raiz deste repositório como diretório público.
